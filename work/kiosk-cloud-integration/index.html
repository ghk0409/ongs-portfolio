01OVERVIEW

무엇을 만들었나

자원 회수 키오스크 기반 서비스의 3인 개발 프로젝트에서 키오스크 프로그램과 앱 서비스를 개발했습니다. 사용자 화면부터 내부 장치 제어, 클라우드 통신과 앱 배포까지 연결했습니다.

02PROBLEM

어떤 문제가 있었나

사용자가 조작하는 화면뿐 아니라 폐자원 검출용 카메라, PLC 제어와 클라우드 서버 간 통신을 구현해야 했습니다. 모바일 앱도 개발 범위에 포함됐습니다.

03CONSTRAINTS

무엇을 바꿀 수 없었나

카메라·PLC 같은 현장 장치와 클라우드 REST API, Android·iOS 앱을 함께 다뤘습니다. 폐자원 검출 모델에는 공개 데이터와 실제 수집 데이터를 사용했습니다.

04ARCHITECTURE / DECISION

어떤 경계를 선택했나

키오스크의 사용자 기능과 내부 장치 작동 프로그램을 개발하고, 카메라와 PLC는 장치 연동으로 연결했습니다. 클라우드 통신은 REST API 인터페이스를 정의하고 토큰 인증을 구현했으며, 모바일 앱은 웹뷰 기반으로 개발했습니다.

05IMPLEMENTATION

어떤 책임을 구현했나

키오스크 화면과 프로그램, 카메라 연동·Serial 통신 기반 PLC 제어를 개발했습니다. 키오스크–클라우드 REST API 인터페이스와 토큰 인증 기능을 만들고 폐자원 검출 모델을 학습했습니다. 웹뷰 기반 앱을 개발해 Android·iOS 배포를 수행했습니다.

06RESULT

무엇이 확인됐나

키오스크 사용자 기능과 장치 제어, 클라우드 통신 기능 및 검출 모델을 개발하고 모바일 앱 배포를 수행했습니다.

07RETROSPECTIVE

무엇을 다시 고려하나

지금 다시 보면 화면·장치·서버·앱을 각각 구현하는 것과 그 접점을 연결하는 일이 모두 필요했습니다. 다음에는 장치별 인터페이스와 연결 동작의 검증 결과를 함께 남겨 서비스 전체에서 맡은 범위를 더 명확히 보여주고 싶습니다.
