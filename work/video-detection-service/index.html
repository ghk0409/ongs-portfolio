01OVERVIEW

무엇을 만들었나

실시간 영상에서 낙상 등 이상행동을 탐지하는 연구개발 프로젝트에서 AI R&D를 담당했습니다. 탐지 데이터셋과 모델 연구뿐 아니라 CCTV 영상 수집 연동과 탐지 시 경고 기능도 개발했습니다.

02PROBLEM

어떤 문제가 있었나

프로젝트에는 영상에서 이상행동을 찾는 모델과, 실시간 CCTV 입력을 받아 탐지 결과를 전달하는 서비스 기능이 함께 필요했습니다. 모델 연구만으로 끝나지 않고 데이터 입력과 결과 활용의 접점을 구현하는 작업이 포함됐습니다.

03CONSTRAINTS

무엇을 바꿀 수 없었나

Linux·Python 환경에서 Jetson Nano와 NAS를 이용한 CCTV 수집 연동을 다뤘고, 2인 프로젝트에서 AI R&D를 담당했습니다. 모델 연구와 함께 영상 입력·경고 알림의 서비스 접점도 개발 범위에 포함됐습니다.

04ARCHITECTURE / DECISION

어떤 경계를 선택했나

객체·자세 기반 탐지와 연속 동작 기반 탐지를 각각 연구했습니다. YOLOv5·PoseNet을 이용한 전처리·학습과 ST-GCN 기반 동작 탐지를 다뤘습니다. 모델 연구와 CCTV 수집·이메일·문자 경고 연동은 서로 다른 작업 범위로 구분했습니다.

05IMPLEMENTATION

어떤 책임을 구현했나

이상행동 데이터셋의 전처리·학습과 모델 연구개발을 수행했습니다. Jetson Nano·NAS를 이용한 실시간 CCTV 영상 수집 연동 서비스를 만들고, 탐지 시 이메일과 문자로 경고를 전달하는 기능을 개발했습니다. 공개 설명에는 실제 영상이나 알림 수신자·운영 설정을 사용하지 않습니다.

06RESULT

무엇이 확인됐나

탐지 데이터셋의 전처리·학습과 모델 R&D를 수행하고, CCTV 수집 연동 및 이메일·문자 경고 기능을 개발했습니다. 모델을 연구하는 일과 영상 입력·결과 전달을 구현하는 일을 함께 경험했습니다.

07RETROSPECTIVE

무엇을 다시 고려하나

지금 다시 보면 연구 항목의 구현과 서비스 적용의 확인은 서로 다른 결과입니다. 탐지 모델을 만들었다는 설명에 그치지 않고 입력 수집·출력 전달의 담당 범위를 보여주는 것이 중요합니다. 다음에는 실험 모델과 최종 적용 모델, 알림 정책 및 운영 검증 결과를 따로 기록해 연구와 서비스의 경계를 더 명확하게 남기고 싶습니다.
