01OVERVIEW

무엇을 만들었나

현장 안전 알림 서비스의 2인 프로젝트에서 AI 활용 IoT 서비스를 개발했습니다. 내부망 구성과 장치 통신, 감지·알림 및 장치 상태 확인을 담당했습니다.

02PROBLEM

어떤 문제가 있었나

네트워크 카메라와 레이더의 감지 기능을 알림 장치와 연결하고, 여러 IoT 장치의 상태를 확인할 수 있어야 했습니다.

03CONSTRAINTS

무엇을 바꿀 수 없었나

IoT 장치·서버·네트워크 카메라가 연결되는 폐쇄망 환경과 Serial 통신 장치를 다뤘습니다. 레이더·릴레이와 전광판·경광등·스피커 등 서로 다른 장치의 연동이 필요했습니다.

04ARCHITECTURE / DECISION

어떤 경계를 선택했나

내부망 네트워크 구조를 설계·적용하고 Redis 서버 및 장치 통신 인터페이스를 정의했습니다. Serial 통신으로 장치를 제어하고, 장치 상태 모니터링에는 heartbeat 기능을 구현했습니다.

05IMPLEMENTATION

어떤 책임을 구현했나

Redis 서버와 통신 인터페이스, 내부망 구조를 개발·적용했습니다. 레이더·릴레이·전광판의 Serial 처리 프로그램, AI 기반 차량·보행자 감지와 OpenCV 신호 검출을 구현했습니다. 알림 장치 연동과 heartbeat를 개발하고 프로그램 리팩토링을 진행했습니다.

06RESULT

무엇이 확인됐나

현장 장치의 감지·통신·알림 기능과 상태 확인용 heartbeat를 개발하고 내부망 구조를 적용했습니다.

07RETROSPECTIVE

무엇을 다시 고려하나

지금 다시 보면 감지 결과를 만드는 것뿐 아니라 장치와 통신이 동작하는지 확인하는 기능도 서비스의 일부였습니다. 다음에는 장치 상태와 감지 결과의 검증 기록을 나눠 남겨 연결 기능과 안전 성능을 구분해 설명하고 싶습니다.
