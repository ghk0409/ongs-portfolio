01OVERVIEW

무엇을 만들었나

음원 장르 분석의 기획·R&D와 음원 감정 분석의 연구·모델링·결과 평가를 수행했습니다. 서로 다른 두 프로젝트의 데이터 처리와 API 접점을 함께 소개하며, 추천 기능·API 개발과는 별도의 분류 분석 작업입니다.

02PROBLEM

어떤 문제가 있었나

사용자 맞춤 추천에 활용할 장르·감정 분석을 위해 음원 데이터셋과 특징 전처리, 분류 모델을 준비하고 분석 결과를 DB와 연결해야 했습니다.

03CONSTRAINTS

무엇을 바꿀 수 없었나

장르 분석과 감정 분석은 참여 인원과 수행 기간이 다른 별도 작업입니다. 데이터셋 구축·특징 처리·모델 테스트와 결과 연동을 각 프로젝트의 범위 안에서 진행했습니다.

04ARCHITECTURE / DECISION

어떤 경계를 선택했나

장르 분석에서는 선행 연구를 참고해 주요 오디오 특징을 선별·추출하고 조합과 모델 설정을 테스트했습니다. 감정 분석에서는 음원 특징별 모델링과 평가·재설계를 진행하고 Thayer 감성 모델을 참고했습니다. 감정 분석의 특징 추출은 자동화하고 결과를 DB 연동 API로 연결했습니다.

05IMPLEMENTATION

어떤 책임을 구현했나

장르별 데이터셋 수집·구축, 오디오 특징 전처리와 분류 모델의 테스트·분석을 수행하고 결과 추출 및 DB 연동 API를 구축했습니다. 감정 분석에서는 데이터셋과 특징 처리, 모델 설계·평가·수정에 참여하고 특징 추출 자동화와 결과 DB 연동 API를 설계했습니다.

06RESULT

무엇이 확인됐나

장르·감정 분류 모델과 데이터 처리 작업을 수행했습니다. 장르 분석 결과의 DB 연동 API를 구축하고, 감정 분석용 특징 추출 자동화 및 결과 API를 설계했습니다.

07RETROSPECTIVE

무엇을 다시 고려하나

지금 다시 보면 모델링과 특징 처리·결과 연동은 서로 다른 책임입니다. 다음에는 실험 설정·평가 결과와 API 입력·출력을 함께 기록해 연구 범위와 서비스 접점을 더 명확하게 남기고 싶습니다.
